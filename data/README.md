# Raw Data Availability

This directory is reserved for the full local set of measured Mountains/DigitalSurf `.sur` topographies used by the benchmark workflows.

The raw SUR files are intentionally excluded from the normal Git-tracked repository snapshot because the dataset is too large for a practical public GitHub repository.

The Git-tracked project snapshot contains the manuscript sources, simulation code, and manuscript-facing generated artefacts. The full raw `.sur` dataset can be shared by the corresponding author upon reasonable request.
